# WebRTC 无存储点对点聊天

两人进入同一房间号即可实时文字聊天。消息通过 WebRTC 的 DataChannel 端到端直连，
**不经过服务器、不存储**。信令服务器只在握手阶段转发 SDP/ICE，用完即弃。

## 运行

```bash
cd D:\SourceCode\webrtc-chat
npm install
npm start
```

然后在浏览器打开两个标签页：`http://localhost:3000`
两个页面输入**相同的房间号**并点击"加入房间"，连接成功后即可互发消息。

## 说明

- 信令服务器仅维护内存中的房间表，无数据库、无持久化日志，重启即清空。
- 聊天内容走 P2P DataChannel，服务器无法读取。
- NAT 打洞依赖网络环境；严格对称 NAT 环境可能需 TURN 中继（本版本暂未包含）。
- 当前为单页设计，连接与聊天在同一页面内。
